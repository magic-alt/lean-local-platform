# 项目、策略与案例模板

策略模板负责生成可编辑的 LEAN 项目；案例模板在策略之上增加市场、股票池、日期、参数网格和研究说明。

点击“使用案例”会创建独立项目副本，并在 `project.json` 中记录 `exampleKey`、`exampleKind` 和 `exampleVersion`。系统模板保持只读，修改副本不会影响其他项目。

## A股策略要求

- 使用 `AShareExecutionHelper` 处理 T+1、整手、费用、停牌和涨跌停。
- 使用真实指数或 ETF 基准。
- 避免未来函数；指数成分和财务数据必须使用当时已公布且已生效的记录。
- 回测成功还需通过结果完整性和执行审计。

参数键应稳定；数值参数应定义最小值、最大值和步长。多策略优化会分别使用各策略自己的参数Schema，不会合并同名但含义不同的参数。

# 单次与批量回测

单次回测用于验证策略、数据和执行规则。批量回测用于横向比较，分为独立矩阵和动态组合两种口径。

## 独立矩阵

独立矩阵按“项目 × 股票 × 时间窗口”展开，每个单元拥有独立资金和LEAN结果。适合单策略覆盖股票池、单股票比较多个策略以及滚动稳定性分析。默认按Sharpe排序，同时查看收益、最大回撤、Calmar、交易数和验证状态。

## 动态组合

动态组合是一个多资产LEAN运行，资金在成分之间共享，并按历史PIT成分调仓。它回答组合实际表现问题，不能与独立单股排名混为一谈。

个别子任务失败不会终止批次。完成后可以仅重试失败项；取消会停止活动容器并取消未派发项目。

# A股指数技术面与基本面筛选

这是一个由 LEAN 执行的动态股票池案例模板。它支持：

- 沪深300（`CSI300`，基准 `000300`）
- 中证500（`CSI500`，基准 `000905`）
- 中证1000（`CSI1000`，基准 `000852`）
- 科创50（`STAR50`，基准 `000688`）

## 筛选规则

每个调仓日只使用当时有效的指数成分、当时已经公告并生效的基本面，以及该日以前的行情：

1. 趋势判断：收盘价、20/60日均线和20日收益共同区分“持续上涨”“持续下跌”“横盘震荡”。
2. 技术评分：均线排列、20日收益、RSI 和20日波动率合计100分。
3. 基本面评分：按可用字段检查 ROE、营收增长、利润增长、资产负债率、PE、PB 和净利润。
4. 买入标准：默认要求持续上涨、技术分不低于70、基本面分不低于60，并至少有2个基本面字段。
5. 组合构建：按综合分选择 Top-N，单票权重不超过10%，并通过 A 股执行助手落实 T+1、涨跌停、停牌、手数、费用和滑点约束。

基本面缺失不会被当作通过。阈值都可以在项目参数中修改。

## 使用

1. 在 Backtests 的案例目录选择“A股指数技术面与基本面选股”。
2. 在 Data 的 TuShare 同步中确保目标窗口已有 `daily_basic`、`income`、
   `balancesheet` 和 `fina_indicator`；同步记录会规范化到 `factor_values` 和
   `financial_facts`。
3. 在批量动态组合表单选择四个支持的指数之一，设置日期和资金。
4. 先预览，确认 PIT 成分和基本面记录可以解析，再提交回测。
5. 在运行目录或 Reports 查看：
   - LEAN 原始结果 JSON；
   - `report.html` 标准回测报告；
   - `screening-report.json` 完整逐股评估；
   - `log.txt` 中的原始结构化筛选记录。

如果目标区间缺少 PIT 成分、公告时点基本面、股票行情或真实指数基准，平台会拒绝运行。筛选结论是可复现的策略规则输出，不构成投资建议。
